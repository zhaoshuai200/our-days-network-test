# 相册手机网络测试

公开的 GitHub Pages 连通性测试。仅包含三张非私人示例插画，不包含真实相册、账号密钥或用户资料。

用手机流量关闭代理访问，检查页面、三张图片和三秒轮播；再用微信打开。可复制页面生成的结果反馈。测试结果仅在浏览器中计算，不主动上传。

发布源：main 分支根目录，GitHub Settings → Pages → Deploy from a branch。

根目录和 `album/` 是公开示例测试页，不提供私人照片上传或访问权限控制。

`private/` 提供另一个独立的加密只读入口。这里的相册数据和媒体文件以 AES-256-GCM 密文存放，浏览器凭单独保管的随机访问密钥解密。密钥不在仓库中，不放入 URL，也不发送到托管服务器。它不是服务器身份认证：密文可公开下载，持有密钥者可以解密，已下载并解密的内容不能远程撤回。原始文件和完整备份留在本地。

`album/` 是已有正式界面的独立功能测试版，全部使用示例插画和虚构日期。4 段记录共 48 个照片条目，由 20 张不同插画重复组合，用于测试 36 张相册、分批备注、精选、主题和放映位置恢复。编辑保存在当前浏览器，不跨设备同步。音乐仅本机试听，不上传、不附带歌曲。不要填写私人信息。
