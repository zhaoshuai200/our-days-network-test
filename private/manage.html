第一次使用：获取上传令牌

在 GitHub 选择 Only select repositories，只勾选 our-days-network-test，权限保留 Contents: Read and write。生成后自己保管，可保存到手机密码管理器，之后直接填入。浏览相册不需要它。

去 GitHub 创建专用令牌 ↗

首张作为封面。网站保存最长边 3200 像素的高清副本；手机里的原始文件请保留备份。

支持 MP3、M4A，最大 12 MB。请选择可在浏览器播放的音频文件。

打开更新后的相册 ↗

上传期间保持此页打开。密钥只在本机使用；写入令牌只发给 GitHub，不写入网站。一批内容一起发布，另一台手机在发布完成后重新打开相册即可看到。
